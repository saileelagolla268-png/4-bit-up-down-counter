# 4-Bit UP/DOWN Counter in Verilog

## Description

This project implements a synchronous 4-bit UP/DOWN counter using Verilog HDL.

The counter can operate in two modes:

- UP counting
- DOWN counting

An active-high synchronous reset is included.
